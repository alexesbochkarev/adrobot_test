# Adrobot React frontend

React + TypeScript + Vite. Все запросы идут на `/api/v1` через прокси к
FastAPI `http://127.0.0.1:8000`. API-ключ Keitaro остаётся только в серверном `.env`.

## Запуск

Для запуска всего проекта одной командой из корня: `docker compose up --build -d --wait`.
Интерфейс будет на <http://localhost:8080>. Подробности — в [основном README](../README.md).
Ниже описан запуск с горячей перезагрузкой для разработки без Docker.

Сначала из корня репозитория запустите backend:

```sh
uv sync --locked
uv run --locked alembic upgrade head
uv run --locked uvicorn adrobot.main:create_app --factory --reload --host 127.0.0.1
```

Затем в другом терминале:

```sh
cd frontend
npm ci
npm run dev
```

Нужен Node.js 20.12+ (в CI используется Node 22). Интерфейс: <http://127.0.0.1:5173>.
Если порт занят, `npm run dev -- --port 5175`. Vite proxy позволяет работать без CORS.

## Сценарии

- Создание кампании: произвольное имя, страна, поиск оффера,
  дополнительные селекты домена, группы и источника.
- Выбор кампании загружает локальное состояние; Fetch отдельно получает его из Keitaro.
- Доли, закрепление, архив, восстановление, добавление оффера и Cancel.
- Push с актуальной версией и ключом идемпотентности; проверка статуса и Reconcile.
- При конфликте обновите локальные данные; для внешних изменений отмените черновик и выполните Fetch.
- При блокировке кампании UUID незавершённой публикации приходит из backend,
  поэтому сверка доступна и после перезагрузки/в другом браузере.

Создание и Push сохраняют ключ операции в localStorage **до** отправки запроса.
Повтор использует тот же ключ. Сохранённое создание можно проверить после перезагрузки.
Не очищайте хранилище после потери связи, пока не выяснен результат записи.
Доли не рассчитываются в браузере: интерфейс показывает подтверждённые ответы backend.

## Проверки и production-сборка

```sh
npm run build
npm run format:check
npx playwright install chromium
npm test
```

Тесты перехватывают все запросы API и не изменяют реальные кампании.
Проверяются создание, добавление оффера, архив/Cancel, версии и идемпотентность Push,
сверка после перезагрузки и мобильный экран. Тестовый сервер использует порт 5179.

Если Playwright не поддерживает загрузку Chromium для вашей ОС, используйте установленный Chrome:

```sh
PLAYWRIGHT_CHANNEL=chrome npm test
```

`npm run build` создаёт `dist/`. Для локальной проверки сборки: `npm run preview`
(порт 4173, также проксирует `/api`). Для внешнего размещения нужен отдельный reverse proxy
к FastAPI и настройка авторизации; публикация не выполнялась.
