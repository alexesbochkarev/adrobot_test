## Повтор проверки

Команда действительно создаёт новую кампанию на сервере из `.env`:

```sh
uv run --locked python scripts/live_smoke.py --run-live
```

Скрипт использует только собственную новую кампанию, уникальный ключ идемпотентности и
блок `finally` для её выключения. При недоступности сервера завершающую проверку состояния
необходимо выполнить вручную по напечатанным имени и ID. Он не входит в обычный pytest/CI.
